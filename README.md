# Экспедитор CRM

Рабочий MVP CRM для экспедиторской компании на Django 5.2 LTS.

Интерфейс построен на UIkit 3.25.21 и использует стандартную визуальную тему UIkit. UIkit загружается
через jsDelivr, поэтому для отображения базовых компонентов требуется доступ
к интернету.

## Возможности

- дашборд с активными заявками, погрузками, маржой и просроченными оплатами;
- заявки на перевозку с маршрутами, грузом, датами, ставками и статусами;
- новая карточка перевозки / рейса с визуальной цепочкой исполнения и
  параллельной синхронизацией действующих заявок;
- разделение нашего исполнителя и фактического перевозчика с отдельным
  назначением водителя, тягача и полуприцепа;
- единый справочник организаций: одна компания может иметь одновременно роли
  клиента, экспедитора, перевозчика, грузоотправителя и грузополучателя;
- справочник нескольких компаний-экспедиторов и раздельная отчётность по ним;
- справочники клиентов и перевозчиков;
- заполнение реквизитов экспедиторов, клиентов и перевозчиков по ИНН через DaData;
- адресные подсказки DaData для точек погрузки и выгрузки;
- сохранение структурированных адресов DaData (ФИАС, индекс, код региона,
  населённый пункт, улица и дом) для подготовки XML ЭПД;
- внутренний личный чат сотрудников с непрочитанными сообщениями и автоматическим обновлением;
- профили водителей с контактами, паспортом, удостоверением и сроками документов;
- подвижной состав с регистрацией, характеристиками, страховкой и техосмотром;
- назначение водителя и транспорта в заявку с проверкой принадлежности перевозчику;
- реестр поступлений от клиентов и выплат перевозчикам с поддержкой частичных оплат;
- дебиторская и кредиторская задолженность, сроки оплаты и автоматическая просрочка;
- поступления и оплаты прямо в карточке проведённого рейса с автоматическим
  отражением в регистре взаиморасчётов;
- финансовые отчёты по периоду и валюте с выручкой, затратами, маржой и помесячной динамикой;
- подготовка и скачивание экспедиторского поручения в редактируемом формате DOCX;
- реестр ТрН, счетов, УПД, актов и счетов-фактур со статусами, сроками и файлами;
- формирование для клиента счетов, актов, УПД и счетов-фактур в DOCX с автоматическим сохранением в реестр;
- реестр договоров с тремя утверждёнными DOCX-шаблонами: ТЭО с клиентом,
  перевозка с перевозчиком и ТЭО с привлечённым экспедитором;
- автоматическая подстановка в договор номера, даты, срока, подписантов и полных
  реквизитов выбранных сторон;
- отдельные реквизиты, банковские данные и ставка НДС для каждого экспедитора;
- поиск и фильтры по заявкам;
- авторизация сотрудников и стандартная административная панель Django;
- адаптивный интерфейс для компьютера и телефона.

## Быстрый запуск

```bash
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python manage.py migrate
python manage.py seed_demo
python manage.py runserver
```

Для заполнения реквизитов по ИНН получите API-ключ в DaData и перед запуском
задайте его только на сервере:

```bash
export DADATA_API_TOKEN="ваш-api-ключ"
python manage.py runserver
```

Ключ не передаётся в браузер. Без него остальные функции CRM продолжат
работать, а при попытке автозаполнения интерфейс покажет подсказку о настройке.

Откройте `http://127.0.0.1:8000/` и войдите:

- логин: `demo`
- пароль: `demo12345`

Учётные данные можно переопределить перед заполнением базы через переменные `DEMO_USERNAME` и `DEMO_PASSWORD`.

## Проверка

```bash
python manage.py test
python manage.py check
```

Для рабочего размещения рекомендуется PostgreSQL, отдельный секретный ключ, `DJANGO_DEBUG=0`, HTTPS и резервное копирование базы. Поскольку профили водителей могут содержать персональные данные, перед эксплуатацией также необходимы разграничение прав сотрудников и журналирование доступа.

### XML для Контур.Диадок

ЭЗЗ в CRM сначала формируется как `UserDataXml`. Это не файл для прямой загрузки
в Контур: перед скачиванием финального `ON_ZAKZVGO.xml` CRM отправляет титул в
метод `GenerateTitleXml` Диадок. Для включения генерации задайте на сервере:

```bash
export KONTUR_DIADOC_API_TOKEN="ваш-access-token"
export KONTUR_DIADOC_API_URL="https://diadoc-api.kontur.ru"
```

В карточке нашей компании заполните поле «Идентификатор участника ЭДО» значением
`boxId` (GUID ящика Диадок). После этого кнопка «XML для Контур» отдаёт ответ
оператора с корнем `Файл` и кодировкой `windows-1251`; при изменении рейса
сохранённый ответ сбрасывается и генерируется заново. Без ключа CRM формирует
русскоязычную локальную копию по структуре образца, а ссылка `UserDataXml`
остаётся доступна для ручного вызова API.
